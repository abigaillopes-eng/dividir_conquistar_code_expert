# Aplicando a técnica Dividir e Conquistar para entender como chamar APIs de LLMs
Esse projeto tem como intuito ajudar a entender como chamar diferentes APIs de LLMs.

# V.0.1
Aqui estamos definindo um contexto de atuação para esses modelos: eles só podem responder a perguntas sobre códigos de programação (em quaisquer linguagens). Caso a pergunta feita fuja desse contexto de atuação, o modelo deve se recusar a responder.

# V.0._

# APIs testadas:
- Anthropic
- Google (Alphabet)
- OpenAI

# Para rodar o projeto
É necessário criar um arquivo .env na raiz do projeto e adicionar as chaves das APIs de LLMs. Tendo o ambiente configurado, basta usar o venv, instalar as dependências e rodar o arquivo ``` main.py ```
